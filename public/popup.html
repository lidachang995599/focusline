Keyboard shortcuts
  • Alt + Shift + F Toggle the reading line
  • Alt + Shift + L Lock or release the line
  • Alt + ↑ / ↓ Move the line
  • Alt + Shift + ↑ / ↓ Make the line taller or shorter
  • Alt + click Place the line on a line of text
  • Alt + right-click Release the lock
  • Esc Stop reading

Change the toggle and lock keys in your browser's extension shortcuts page.
