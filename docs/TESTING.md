# FocusLine 测试指南

## 0. 准备

- Chrome / Edge 114 以上。
- 不需要 `npm install`：`D:\fantasy\focusline\dist` 已经是构建好的扩展。
- 如果改了源码，先 `npm run build` 再重新加载扩展。

## 1. 安装（1 分钟）

1. 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择 `D:\fantasy\focusline\dist`
5. 在工具栏把 FocusLine 图标固定出来（拼图图标 → 图钉）

安装后先**刷新一次要测试的页面**，再点图标。

## 2. 五分钟冒烟测试

打开一篇长文（维基百科、新闻站、公众号文章都行），按顺序做：

| # | 操作 | 预期 |
|---|---|---|
| 1 | 点工具栏图标 | 弹窗打开；**首次页面没有亮带**（默认关闭） |
| 2 | 打开弹窗右上角开关 | 亮带出现，页面上下变暗 |
| 3 | 拖右侧圆点上下移动 | 亮带跟随，页面其余部分始终变暗 |
| 4 | 按 `Alt + ↑ / ↓` | 亮带微调；加 `Shift` 调高度 |
| 5 | 拖「Line height」「Dim」滑杆 | 实时变化 |
| 6 | 点五个颜色圆点 | 亮带颜色变化 |
| 7 | 刷新页面 | 线还在，位置/高度/颜色都保留 |
| 8 | 点弹窗右上角开关 / 按 `Alt + Shift + F` | 线消失；再按一次回来 |
| 9 | 换一个网站，再换回来 | 新网站默认关闭；原网站记忆还在 |
| 10 | 勾选「Run automatically on this site」 | Chrome 弹出该域名授权 → 允许；刷新后线自动出现 |
| 11 | 点「Hide an element…」，再点页面上的 cookie 横幅 | 横幅消失；按钮变成「Reset hidden」 |
| 12 | 打开 `chrome://extensions` 再点图标 | 弹窗显示「This page cannot be used with extensions.」 |

11 步都过，核心功能就是好的。

- [ ] 换到同域名的其他页面，自动生效

### 排版调整

- [ ] `A` 滑杆调到 120%，页面整体放大（浏览器缩放），刷新后仍保持

### 朗读

- [ ] 点「Read aloud」：从光线所在的词开始读，而不是从页面顶部开始
- [ ] 当前句有底色，当前词有更深的底色

- [ ] 句子仍在视口内时，光线保持不动，只有句子高亮在移动
- [ ] 当前句离开视口时，页面滚回视口内，光线移到该句
- [ ] 朗读期间移动鼠标，光线不会被跟随鼠标拽走
- [ ] 「Highlight colour」的 6 个颜色都能切换；切色后当前句/词立即变色
- [ ] 按钮变为「Pause」；点一次暂停，再点变「Resume」继续
- [ ] 点 `■` 或按 `Esc` 停止，高亮消失
- [ ] 语速滑杆调到 1.5×，下一句开始变快
- [ ] 「Reading language」选 Auto：日文（含假名）用日语语音，韩文用韩语语音，中文用中文语音
- [ ] 日文页面里的汉字用日语读音，不再是中文读音
- [ ] 手动锁定「Japanese / Korean」，中文页面也会用对应语言语音
- [ ] 系统没装日语本地语音时提示 `No local voice available (ja)`，不会改用中文语音

- [ ] 系统没有本地语音时提示「No local voice available」，不会发出网络请求
- [ ] 关掉阅读线开关后朗读停止

### 可访问性与 RTL

- [ ] 屏幕阅读器：5 个滑杆分别读作 线高 / 暗度 / 字号 / 正文行高 / 字距
- [ ] 屏幕阅读器：语言下拉框有名称，不再只读 “combobox”
- [ ] 焦点移到阅读线手柄：方向键可上下移动，读出的百分比随位置变化，方向为垂直
- [ ] 中文界面：主题圆点读作 默认 / 纸色 / 深色 / 高对比
- [ ] 颜色圆点读作 天蓝 / 琥珀黄 / 紫罗兰 / 绿色 / 玫红，而不是 `#7dd3fc`

### 刷新与持久化

- [ ] 打开线后刷新页面：线不会自动出现（Chrome 权限限制，正常现象）
- [ ] 刷新后点图标：开关应仍是「开」，线回来（不再显示为关闭）
- [ ] 勾选「Run automatically on this site」并允许权限后刷新：线自动出现

### 不支持页面
- [ ] `chrome://extensions`
- [ ] Chrome 应用商店页面
- [ ] PDF 查看器
- [ ] `file://` 本地文件（预期不支持）

### 多语言与 RTL

1. 打开弹窗，底部「Language」下拉 → 选 العربية / 日本語 / Deutsch
2. 弹窗会刷新一次并变成该语言；重新打开弹窗确认选择被记住
3. 打开一个新标签页（内容脚本的提示文案在下一次注入时生效），确认 HUD 也是该语言
4. 阿拉伯语/波斯语/希伯来语下，确认开关滑块方向、文字对齐正常
5. 选回「Auto」，确认界面恢复成 Chrome 的 UI 语言

想测「Auto 跟随浏览器」：到 `chrome://settings/languages` 把目标语言设为第一项，重启 Chrome，确认弹窗自动切换。

### 隐私
- [ ] 打开弹窗 → 右键「检查」→ Network 面板，操作一圈，确认没有任何请求
- [ ] 页面 DevTools → Network，确认内容脚本没有发请求

## 4. 出问题怎么查

| 位置 | 怎么打开 | 看什么 |
|---|---|---|
| 弹窗 | 弹窗内右键 → 检查 | Console 报错 |
| Service worker | `chrome://extensions` → 扩展卡片 → 「Service worker」 | Console、`chrome.storage.local.get(console.log)` |
| 内容脚本 | 页面 DevTools → Console | 来自扩展的报错（通常在 isolated world） |
| 快捷键冲突 | `chrome://extensions/shortcuts` | `Alt + Shift + F` 是否被占用 |

常见现象：

- **点了图标线没出现**：先刷新页面；确认是 `http/https` 页面；看 Service worker 有没有报错。
- **弹窗显示 Reload the page**：页面可能刚导航过，刷新再点。
- **自动启用没生效**：确认 Chrome 的域名授权弹窗点了「允许」；`chrome://extensions` 里看扩展的「网站访问权限」。
- **隐藏元素后页面乱了**：点「Reset hidden」；或到 Service worker 里 `chrome.storage.local.clear()`。
- **完全重置**：`chrome://extensions` → 移除扩展 → 重新「加载已解压」。
